El programa comenzo a crearse desde la clase Dado y JuegoDados las cuales consisten las bases del codigo posterior.
Una vez relizadas y conectadas estas clases se crearon las clases JuegoVersus (encargado del 1v1 de los jugadores) y versus (encargada de de la funcion del juego en si) y se diseño el sistema de manera para que al crear los usuarios, estos tengan una puntuacion que aumente por iteracion si gana en los repetidos juegos.
Los usuarios solo se crean en la primera partida, pues estos permanecen eternamente solo cambiando la puntuacion hasta que termine el juego.
La clase calculadora solo funciona de apoyo a la clase de JuegoDados
Finalmente se realizó el testing para comprobar la funcionalidad y todo dio positivo
